Aim: Study and implementation of Infrastructure as a Service

Steps:
1. Download "Oracle VirtualBox" from their website.
2. Download the .ova file of the Univention ownCloud app for VirtualBox using this link:
   https://appcenter.software-univention.de/univention-apps/current/owncloud/Univention-App-owncloud-virtualbox.ova
3. After downloading, open the file. It will directly open the VirtualBox interface. Click "Finish" on the configuration pop-up and accept the Software License Agreement.
4. The virtual machine will be installed automatically and will appear on the left of the interface.
5. Before starting the virtual machine, open Settings (top middle of the interface).
6. Go to the System section, select the Processor tab, set the processor to 2 cores, leave the rest as it is and click "OK".
7. Start the virtual machine.
8. On the next window it asks for your "city". Do NOT enter any city name, just click "NEXT" (most important step - otherwise it will not read keyboard entries).
9. Click "NEXT" on the "Localization settings" window.
10. The next window fetches the IP Address, Net Mask and Gateway from DHCP. Don't change anything and click "NEXT".
    If it cannot fetch the IP address automatically, set it manually: use "ipconfig" in the cmd prompt, then enter an IPv4 address that is not currently in use in your network, keep the gateway address as shown in cmd, and keep the net mask the same. Click "NEXT".
11. On "Domain setup" keep "Manage users and permissions directly on this system (Recommended)" and click "NEXT".
12. On "Account information" enter your name (organisation name), an email address and a password. Remember the password, it is needed in later steps.
13. The next window shows the Fully Qualified Domain Name and LDAP base. Click "NEXT".
14. The configuration settings for ownCloud are shown. Uncheck "Update system after setup", scroll down a little and click "CONFIGURE SYSTEM".
15. Setup takes some time. When it is done, click "FINISH", then press any key on the next window.
16. The virtual machine restarts automatically.
17. Once it has booted, open a web browser and enter the IP address you configured in the "Domain and Network Configuration" step.
18. It asks for an Email ID to send the license to. Enter your Email ID and click "REQUEST ACTIVATION".
19. Check your mailbox, download the license received from ownCloud, go back to ownCloud, click "UPLOAD LICENSE FILE", select the license file and click "Open".
20. On the next page ("Activation successful!") click "FINISH".
21. ownCloud is now installed. Log in with "Administrator" as the user name and the password set during setup, then click "LOGIN".
22. The ownCloud Portal opens. ownCloud installation is complete.

Aim: Study and Implementation of storage as a Service

Theory:
- Storage as a service (SaaS) is a business model in which a company leases or rents its storage infrastructure to another company or individuals to store data. Small companies and individuals often find this to be a convenient methodology for managing backups, and it provides cost savings in personnel, hardware and physical space.
- A company providing SaaS may be called a storage service provider (SSP). Storage as a service can also be referred to as hosted storage.
- Storage as a Service is a business model in which a large company rents space in their storage infrastructure to a smaller company or individual.
- In the enterprise, SaaS vendors are targeting secondary storage applications by promoting SaaS as a convenient way to manage backups. The key advantage to SaaS in the enterprise is in cost savings - in personnel, in hardware and in physical storage space.
- For instance, instead of maintaining a large tape library and arranging to vault (store) tapes offsite, a network administrator that used SaaS for backups could specify what data on the network should be backed up and how often it should be backed up.

Aim: Study and implementation of Identity Management

Theory:
- Identity management (ID management) is the organizational process for identifying, authenticating and authorizing individuals or groups of people to have access to applications, systems or networks by associating user rights and restrictions with established identities. The managed identities can also refer to software processes that need access to organizational systems.
- Identity management includes authenticating users and determining whether they're allowed access to particular systems. ID management works hand-in-hand with identity access management systems. Identity management is focused on authentication, while access management is aimed at authorization.
- ID management determines whether a user has access to systems, but also sets the level of access and permissions a user has on a particular system. For instance, a user may be authorized to access a system but be restricted from some of its components.
- The main goal of identity management is to ensure that only authenticated users are granted access to the specific applications, systems or IT environments for which they are authorized. This includes control over user provisioning and the process of onboarding new users such as employees, partners, clients and other stakeholders. Identity management also includes control over the process of authorizing system or network permissions for existing users and the offboarding of users who are no longer authorized to access organization systems.

6. Enter a device name, select "Authenticator app" (virtual MFA device) and click "Next/Continue".
   Concept: a third-party app generates a one-time password (OTP) which helps us authenticate ourselves while logging in. It adds a security layer to the account.
7. Download an authenticator app such as "2FAS Authenticator" on your mobile. Click "Show QR code" on the AWS page to display the QR code.
8. Open the app, click "Continue", click the "+" button and choose "Scan QR code" to scan the code.
9. Enter two consecutive OTPs (MFA Code 1 and, after 30 seconds, MFA Code 2) received on the app and click "Add MFA" / "Assign MFA". Click "Close". The message "MFA device assigned" is shown.
10. Log out from the account (Sign out).
11. Log in again. It will ask for the MFA code. A new code is generated every 30 seconds - enter the valid MFA code and click "Sign in" to log in.

Aim: User Management in Cloud

Theory:
- User management describes the ability for administrators to manage user access to various IT resources like systems, devices, applications, storage systems, networks, SaaS services, and more.
- User management is a core part to any directory service and is a basic security essential for any organization.
- User management enables admins to control user access and on-board and off-board users to and from IT resources.
- Subsequently a directory service will then authenticate, authorize, and audit user access to IT resources based on what the IT admin had dictated.
- Traditionally, user management has been grounded with on-prem servers, databases, and closed virtual private networks (VPN). However, recent trends are seeing a shift towards cloud-based identity and access management (IAM), granting administrators even greater control over digital assets.

Aim: Hosting a static website on Google App Engine (Firebase Hosting)

Procedure:
Step 1: Sign up with your Gmail account on Google's Firebase and create a project in Firebase.
Step 2: You will be forwarded to the Project Overview page of your project.
Step 3: Go to the cmd prompt and run:
    npm install -g firebase-tools
Step 4: Log in to Firebase from the cmd prompt:
    firebase login
    (Answer the prompts; after authentication it shows "Success! Logged in as <your gmail>".)
Step 5: Go to the desktop and create a new folder.
Step 6: Open the cmd prompt in the newly created folder and run:
    firebase init hosting
    and choose the options as prompted:
      - Please select an option: Use an existing project
      - Select a default Firebase project for this directory: <your project>
      - What do you want to use as your public directory? public
      - Configure as a single-page app (rewrite all urls to /index.html)? Yes
      - Set up automatic builds and deploys with GitHub? No
Step 7: Go to the newly created folder; you will see these files/folders added: .firebase, public, .firebaserc, firebase.json.
Step 8: Create an index.html file with simple HTML code that displays "hello world".
Step 9: Paste the same file in the public folder (if there is already an index.html file inside, replace it with the one you created).
Step 10: Go to the cmd prompt and run:
    firebase deploy
Step 11: After deploying, click on the link mentioned in "Hosting URL" (e.g. https://practical-574e7.web.app). The page shows "hello world".
Step 12: To disable the website after deploying, run:
    firebase hosting:disable

# Setup (do this first):
# 1. Open the Dropbox App Console and create a new app (Scoped access, Full Dropbox).
# 2. In Permissions enable files.content.read and files.content.write, then click Submit.
# 3. Generate the access token and paste it into ACCESS_TOKEN below.
# 4. Install the library: pip install dropbox
# 5. Create a text file named test.txt next to this script.

import dropbox
import os

ACCESS_TOKEN = "YOUR ACCESS_TOKEN"

dbx = dropbox.Dropbox(ACCESS_TOKEN)

def upload_file(local_path, dropbox_path):
    with open(local_path, "rb") as f:
        dbx.files_upload(f.read(), dropbox_path, mode=dropbox.files.WriteMode("overwrite"))
        print(f"Uploaded '{local_path}' to {dropbox_path}")

def download_file(dropbox_path, local_path):
    metadata, res = dbx.files_download(dropbox_path)
    with open(local_path, "wb") as f:
        f.write(res.content)
    print(f"Downloaded '{dropbox_path}' to '{local_path}'")

if __name__ == "__main__":
    upload_file("test.txt", "/test.txt")
    download_file("/test.txt", "download.txt")
